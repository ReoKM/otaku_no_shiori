## 1. 調査

### 1-1. 参考スクリーンショットの分析(フードシェアリングアプリのモック)

- 下部バーは画面端に張り付いておらず、**周囲に余白を持って浮いた白い角丸パネル**(強めのドロップシャドウ)
- 選択中タブ(Map)はパープル文字+下線、非選択(List)はグレー。**中央に紫の円形「+」ボタンがバー上端からせり出す**
- 全体にゆとりのある余白・大きめ角丸・パープルのアクセント1色という統制されたデザイン言語

### 1-2. メモ・TODO・管理系アプリのUIパターン調査

| アプリ系統 | 下部ナビの造形 | ページ/画面切り替え |
|---|---|---|
| Apple純正メモ / Bear | フラット。ナビはリスト階層で、タブバー無しか標準タブバー | 横スライドのみ。紙メタファー無し |
| GoodNotes / Notability(物理ノート風) | ツールバー型 | **ページめくり(左右スワイプ+ページカール寄りの演出)**。紙の質感・綴じ表現あり |
| Things 3 / Todoist / TickTick | 標準ボトムタブまたはFAB+タブ。Todoistは中央寄りFABが浮く | フェード/スライド。装飾控えめ |
| Google Keep | 下部バー+**中央せり出しFAB**(参考画像と同型) | フェード |
| 2025-26トレンド(Material/UXPin/Aceternity調べ) | **ピル型・浮遊型ボトムバー**(周囲余白+丸み+影)、埋め込み型中央FABが審美・親指到達性の両面で好評 | ジェスチャー(横スワイプ)併用が標準化 |

示唆: 「紙のノート感」はGoodNotes系(コンテンツ側=紙・めくり)が担い、「操作系の今っぽさ」はKeep/Todoist系(浮遊バー+円形せり出し)が担う、という役割分担が既存アプリでも成立している。コンテンツ=スキュームォーフィック、ナビ=モダン浮遊、の併存は違和感を生まない。

### 1-3. CSSページめくり技法の調査

- WebGLなしでも「`transform-origin`を綴じ側に置いた`rotateY`+動く`box-shadow`+陰影グラデーション」で説得力のあるめくりが作れる(Creative Bloq、CodePenのPure CSS3 Page Flip等)
- 捲れ感の鍵は(1)**出ていく紙(リーフ)自体が回転して払われること**、(2)回転中の紙に落ちる陰影、(3)加速度(実物の紙は倒れ込むほど速くなる=ease-in系)
- View Transitions APIで旧ページのスナップショットを退場アニメーションさせる手もあるが、ブラウザ対応とNext.js App Routerとの統合コストが高い

## 3. 採用した方向性と理由

### 「本のインデックスタブ」コンセプトの扱い

前回④の「小口から見出しタブが覗く」**形状は廃止**し、DNAである「**選択中がせり出す**」を円形ポップアウトとして継承する。理由:

1. 札形状はバー端への接地が前提で、浮遊パネルと両立しない(B-1の却下理由)
2. ノートらしさは綴じリング・紙質感・ページめくり(コンテンツ側)が既に担っており、ナビまで紙に寄せる必要がない(1-2の示唆)
3. オーナー指示は参考画像の浮遊デザイン言語の採用であり、こちらを優先する

### A. ページめくり v2(リーフフリップ)

- 進む(next): 新ページは下敷きとしてほぼ静止(ごく小さな滑り込みのみ)。その上を「めくられた前ページの裏面」(`.s3-page-turn-next::before`、紙色+綴じ側陰影のグラデーション)が綴じ軸`rotateY 0→-100deg`で払われる。`backface-visibility: hidden`により90度を超えた瞬間に自然に消える。easingはease-in系(紙が倒れるほど加速)
- 戻る(prev): 新ページ自体が「左に倒してあった紙が起き上がって開く」動き(`rotateY -75deg→0`、ease-out系=開き切る直前に減速)。回転中は綴じ側に陰影オーバーレイを重ね、開き切ると消す
- いずれもCSS transform/box-shadow/gradientのみ。ライブラリ追加無し。`prefers-reduced-motion: reduce`ではアニメーション無し(維持)
- 時間は0.45s(現行0.3sでは紙の回転を目が追えないため延長。0.5s超は操作の待ちに感じるため上限とする)

### B. 下部バー v2(浮遊ピル+円形せり出し)

- バー: `fixed`のまま画面端から左右12px・下12px+セーフエリア浮かせ、`rounded-full`のピル形状+`border-neutral-200`+`shadow-xl`。中央寄せ`max-w-md`(PC時もコンテンツ幅に揃う)
- タブ: 4等分のまま、アイコン(インラインSVG、線画)+ラベル(`text-caption`)の縦積みに変更。ラベル文言は文言一覧のまま
- 選択中: アイコンを44px円(`bg-pink-500`=`color-primary`、白アイコン、`shadow-lg`)に収め、負マージンでバー上端から約14pxせり出させる。ラベルは`color-primary-soft-text`+`font-semibold`。`aria-current="page"`維持
- 非選択: アイコン・ラベルとも`color-text-secondary`
- タップ領域: 各タブはバー全高64px×約88px(375px時)で44px以上を維持
- `--s3-tabbar-height`はバー高64px+下オフセット12px+上の抜け余白16px+セーフエリアに更新(sticky入力フォームは紙の下端に揃って止まる)
- アイコンは持ち物=バッグ / TODO=チェック付き四角 / 旅程=マップピン / ログ=ペン。線画・`currentColor`・24px viewBoxのインラインSVG(アセット・ライブラリ追加無し)

### 使用トークン

新規トークン・新規生色は追加しない。`color-primary`(pink-500)/`color-primary-soft-text`(pink-700)/`color-text-secondary`(neutral-500)/`color-border-default`(neutral-200)/`shadow-lg`/`shadow-xl`/`radius-full`/`text-caption`のみ。陰影グラデーションは既存`.s3-*`と同じ`oklch(0% 0 0 / α)`(黒の透過)を使う。
