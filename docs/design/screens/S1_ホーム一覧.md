# S1 ホーム/しおり一覧

対応機能: F1(一覧・CTA導線)/ F9(広告枠は位置確保のみ) / 参照: `docs/01_service_spec.md`
ルーティング: `/`
デザイントークン: `docs/design/tokens.md`

## 前提(W1スコープの補足)

W1はゲスト(未ログイン)専用。ログイン状態の概念がまだ無いため、「新規訪問者向けのランディング」と「しおり0件の空状態」を分ける手段がない(判定材料はIndexedDB内のしおり件数のみ)。そのため本仕様では**空状態がそのままランディング(サービス説明+CTA)を兼ねる**。S6(設定/アカウント)はW1未実装のため、ヘッダーに設定導線は置かない。

## レイアウト(上から順)

配色・書体・角丸は `docs/design/tokens.md` の紙テイストトークンに従う。左右余白は`space-6`(24px)でS3と揃える。

1. **ヘッダー**(`sticky top-0`、`paper-surface`背景、下端に`paper-border`)
   - サービス名「オタクのしおり」(20px / 900)
2. **一覧**(`ShioriCard`を縦に並べる。カード間`space-3`)
   - 0件のときは`EmptyState`
   - 読込中は`ShioriListSkeleton`(カード形×2枚)
   - 読込失敗時は破線カードのエラーブロック
3. **広告枠**(F9。破線枠のプレースホルダー)
4. **フッター**(利用規約 / プライバシーポリシー)
   - しおりが1件以上あるときは`FabButton`と重ならないよう下余白を`pb-24`に広げる
5. **FabButton**(しおりが1件以上あるときだけ、右下に固定)


## コンポーネント構造

```
<Header>
  <ServiceLogo text="オタクのしおり" />
</Header>
<Main>
  {shioriList.length === 0
    ? <EmptyState />
    : <ShioriList>
        <ShioriCard × N />
      </ShioriList>}
  <AdSlotPlaceholder />
</Main>
<FabButton />  // しおり1件以上の時のみ画面下部に固定表示
```

### EmptyState(空状態ブロック)

初回訪問者が最初に見る画面のため、他タブの空状態(破線カード)より一段強い「表紙」の扱いにする。
枠線は実線(`paper-border`)、面は`paper-surface`:

- 見出し(22px / 900 / `ink`): 「遠征のすべてを、1冊のしおりに。」(2行に折る)
- 説明(13px / `ink-sub` / 行間1.9): 「ライブも、イベントも、聖地巡礼も。持ち物・やること・旅程をひとつにまとめて、遠征当日は片手でサクサク確認。」
- 補足(12px / `ink-muted`): 「登録なしで、いますぐ無料で使えます」
- 主ボタン(`sakura`背景、`radius-btn`、高さ52px、全幅): 「＋ 最初のしおりを作る」

### ShioriCard(一覧状態・1件分)

S3のリスト行と同じ「紙のカード+シェブロン」の作り。カード全体が1つのボタン:

1. `CoverAvatar`(44×44pxの角丸。色プリセットはベタ塗り、絵文字は`paper-border`枠+`paper`背景)
   - 円ではなく角丸にして、S3のチェックボックスやカードと同じ「紙に貼ったラベル」の印象に揃える
2. タイトル(16px / 700 / `ink`、1行でtruncate)
3. 日程(12.5px / `ink-sub`)
4. 遠征タイプのバッジ(`sakura-soft`背景 / `sakura-ink`文字 / `radius-full`)
5. 右端にシェブロン(`ink-faint`)

### FabButton

しおりが1件以上あるときだけ右下に固定表示する。S3の追従ボタンと同じ
「白地 + `sakura-border`枠 + `sakura-ink`文字」のピル(高さ50px)で、＋アイコンと文言「しおりを作る」を並べる。

**＋アイコンだけの円形FABにはしない。** 何が作られるか分からないため、文言を必ず添える。


## 状態

| 状態 | 表示 |
|------|------|
| ローディング(IndexedDB読込中) | メインエリアに簡易スケルトン(カード形の`color-bg-disabled`背景ブロックを2枚、アニメーションはfrontend-dev実装裁量)。ヘッダーは通常表示 |
| 空(しおり0件) | EmptyState表示(ランディング文言+CTA)。広告枠プレースホルダーも表示 |
| 一覧(しおり1件以上) | ShioriCardを作成日時の新しい順(`created_at`降順)に縦積み表示。カード間`space-3`。最下部に広告枠プレースホルダー。FabButton表示 |
| 読込エラー(IndexedDBアクセス失敗) | 破線カードに「しおりを読み込めませんでした」(`ink-strong`)+補足「通信は使っていないので、開き直すと直ることがあります」(`ink-sub`)+「再読み込み」ボタン(白地+`sakura-border`枠) |
| オフライン | データは端末内(IndexedDB)のみを参照するため、通信不要でローディング/空/一覧の各状態はオンライン時と同じ表示になる。オフライン専用の表示分岐は無し |

## タップ時の挙動

| 要素 | 挙動 |
|------|------|
| EmptyStateの「＋ 最初のしおりを作る」ボタン | `/shiori/new`(S2)へ遷移 |
| FabButton(＋） | `/shiori/new`(S2)へ遷移 |
| ShioriCard | そのしおりの`id`で`/shiori/[id]/packing`(S3a・持ち物タブ)へ遷移。しおり詳細を開いた時点のデフォルトタブは持ち物タブとする |
| 読込エラー時の「再読み込み」ボタン | IndexedDBの読み込み処理を再実行する |
| 広告枠プレースホルダー | タップ不可(W1では中身が無いため) |

## 遠征当日の利用シーン確認

- 片手操作: FabButton・CTAボタンともに親指が届きやすい画面下部/右下に配置。カードタップ領域はカード全体でタップミスを防ぐ
- 移動中/電波弱い: 表示データはIndexedDBのみで完結し通信不要。広告枠は中身が無いためレイアウトシフトの原因にならない(将来実装時は固定高さ確保済みの枠内に収める)
