# S1 ホーム/しおり一覧

対応機能: F1(一覧・CTA導線)/ F9(広告枠は位置確保のみ) / 参照: `docs/01_service_spec.md`
ルーティング: `/`
デザイントークン: `docs/design/tokens.md`

## 前提(W1スコープの補足)

W1はゲスト(未ログイン)専用。ログイン状態の概念がまだ無いため、「新規訪問者向けのランディング」と「しおり0件の空状態」を分ける手段がない(判定材料はIndexedDB内のしおり件数のみ)。そのため本仕様では**空状態がそのままランディング(サービス説明+CTA)を兼ねる**。S6(設定/アカウント)はW1未実装のため、ヘッダーに設定導線は置かない。

## レイアウト(上から順)

1. **ヘッダー**(`sticky top-0`、背景`color-bg-surface`、下境界`color-border-default`)
   - サービス名ロゴテキスト「オタクのしおり」(`text-heading-lg` / `color-text-primary`)
   - 右上に何も置かない(S6未実装のため設定アイコンは無し)
2. **メインエリア**(左右余白`space-4`、上下`space-4`)
   - 状態により「空状態ブロック」または「しおり一覧」を表示(下記参照)
3. **広告枠(F9・位置確保のみ)**
   - 一覧の最下部・画面最下部に配置
   - **W1では枠のみ確保し、中身は実装しない**(F9本実装はW3スコープ。`docs/plans/2026-W28.md`参照)
   - 枠デザイン: 高さ80px程度、`color-ad-placeholder-bg`背景、`color-ad-placeholder-border`の破線枠(`radius-md`)、中央に`text-caption`/`color-ad-placeholder-text`で「広告枠(準備中)」の文字のみ

## コンポーネント構造

```
<Header>
  <ServiceLogo text="オタクのしおり" />
</Header>
<Main>
  {shioriList.length === 0
    ? <EmptyState />
    : <ShioriList>
        <ShioriCard × N />
      </ShioriList>}
  <AdSlotPlaceholder />
</Main>
<FabButton label="しおりを作る" />  // しおり1件以上の時のみ画面下部に固定表示
```

### EmptyState(空状態ブロック)

- キャッチコピー(`text-heading-md`): 「推しの遠征、しおりで身軽に」
- 説明文(`text-body` / `color-text-secondary`): 「持ち物・TODO・旅程をひとつにまとめて、遠征当日も片手でサクサク確認できます。登録なしですぐ使えます。」
- CTAボタン(`color-primary`背景、`text-button`、`radius-md`、高さ44px以上、幅は画面いっぱい): 「しおりを作る」

### ShioriCard(一覧状態・1件分)

レイアウト(横並び、`radius-lg` / `color-bg-surface` / `color-border-default`枠 / パディング`space-4`):

1. 左: カバー表示(40×40px、`radius-full`)
   - カバーが`color:`形式 → その色で単色の円
   - カバーが`emoji:`形式 → 円の背景`color-bg-app`に絵文字を中央表示
2. 右: テキスト情報(縦積み、`space-1`間隔)
   - タイトル(`text-body` font-semibold、`color-text-primary`、1行省略`truncate`)
   - 日程(`text-body-sm` / `color-text-secondary`): 「2026/08/01〜2026/08/02」形式(開始日=終了日の場合は「2026/08/01」のみ表示)
   - 遠征タイプバッジ(`text-caption`、`color-primary-soft`背景 + `color-primary-soft-text`文字、`radius-full`、内側パディング`space-2`横/`space-1`縦): 「ライブ/イベント参戦」「聖地巡礼」「舞台/観劇」「その他」のいずれか

カード全体をタップ可能領域とする(タップ時の挙動は下記)。

### FabButton

- しおりが1件以上ある場合、画面右下に固定表示する丸型ボタン(56×56px、`radius-full`、`color-primary`背景、白文字「＋」)。空状態の時はEmptyState内のCTAボタンのみでFabButtonは表示しない(CTAの二重掲示を避けるため)

## 状態

| 状態 | 表示 |
|------|------|
| ローディング(IndexedDB読込中) | メインエリアに簡易スケルトン(カード形の`color-bg-disabled`背景ブロックを2枚、アニメーションはfrontend-dev実装裁量)。ヘッダーは通常表示 |
| 空(しおり0件) | EmptyState表示(ランディング文言+CTA)。広告枠プレースホルダーも表示 |
| 一覧(しおり1件以上) | ShioriCardを作成日時の新しい順(`created_at`降順)に縦積み表示。カード間`space-3`。最下部に広告枠プレースホルダー。FabButton表示 |
| 読込エラー(IndexedDBアクセス失敗) | メインエリアに「しおりの読み込みに失敗しました」(`color-error`)+「再読み込み」ボタン(アウトライン、`color-primary`文字) |
| オフライン | データは端末内(IndexedDB)のみを参照するため、通信不要でローディング/空/一覧の各状態はオンライン時と同じ表示になる。オフライン専用の表示分岐は無し |

## タップ時の挙動

| 要素 | 挙動 |
|------|------|
| EmptyStateの「しおりを作る」ボタン | `/shiori/new`(S2)へ遷移 |
| FabButton(＋） | `/shiori/new`(S2)へ遷移 |
| ShioriCard | そのしおりの`id`で`/shiori/[id]/packing`(S3a・持ち物タブ)へ遷移。しおり詳細を開いた時点のデフォルトタブは持ち物タブとする |
| 読込エラー時の「再読み込み」ボタン | IndexedDBの読み込み処理を再実行する |
| 広告枠プレースホルダー | タップ不可(W1では中身が無いため) |

## 遠征当日の利用シーン確認

- 片手操作: FabButton・CTAボタンともに親指が届きやすい画面下部/右下に配置。カードタップ領域はカード全体でタップミスを防ぐ
- 移動中/電波弱い: 表示データはIndexedDBのみで完結し通信不要。広告枠は中身が無いためレイアウトシフトの原因にならない(将来実装時は固定高さ確保済みの枠内に収める)
