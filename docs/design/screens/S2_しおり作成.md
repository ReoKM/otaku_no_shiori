# S2 しおり作成

対応機能: F1 / 参照: `docs/01_service_spec.md`
ルーティング: `/shiori/new`
デザイントークン: `docs/design/tokens.md`

## レイアウト(上から順)

配色・書体・角丸は `docs/design/tokens.md` の紙テイストトークンに従う。左右余白は`space-6`(24px)。

1. **ヘッダー**(`sticky top-0`、`paper-surface`背景、下端に`paper-border`)
   - 左に戻るボタン(44×44px)、中央に「しおりを作る」(20px / 900)
2. **入力欄**(縦に`space-6`間隔で並べる)
   - タイトル / 日程 / 遠征タイプ / 目的 / カバー
3. **送信ボタン**(`sticky bottom-0`、`paper-surface`背景、上端に`paper-border`)

### 入力欄の共通ルール

| 要素 | 指定 |
|---|---|
| 見出しラベル | 13px / 700 / `ink-label`。入力欄の上に置く |
| 補助ラベル(開始日・終了日など) | 12px / 500 / `ink-muted` |
| 入力欄 | 高さ48px以上、`radius-md`(12px)、枠線1.5px、`ink`の中太。**通常時は`paper-dashed`、フォーカス時は`sakura-field`** |
| プレースホルダー | `ink-faint`の標準ウェイト(入力値と見分けがつくよう細くする) |
| エラー時の枠線 | `color-error-border` |
| エラー文言 | 12px / 500 / `color-error`。入力欄の下 |
| 文字数カウンタ | 12px / `ink-muted`。入力欄の右下 |


## コンポーネント構造

```
<Header>
  <BackButton />
  <Title text="しおりを作る" />
</Header>
<Form onSubmit={createShiori}>
  <FieldTitle />          // テキスト入力・必須
  <FieldDateRange />       // 開始日・終了日
  <FieldTripType />        // 単一選択チップ4種
  <FieldPurpose />         // テキスト入力・任意
  <FieldCover />           // 色/絵文字トグル + プリセット選択
  <SubmitBar>
    <SubmitButton label="しおりを作る" />
  </SubmitBar>
</Form>
```

### 1. FieldTitle(タイトル)

- ラベル(`text-body-sm` font-semibold、必須マーク付き): 「タイトル ※必須」
- テキスト入力(1行、`radius-md`、`color-border-default`枠、高さ44px以上、`color-bg-surface`背景)
- プレースホルダー: 「例: ○○ちゃん生誕祭 東京遠征」
- 文字数上限: **30文字**(仮置き。仕様に数値指定が無いため。詳細は完了報告の「不明点・仮置き」参照)
- 入力欄下に右寄せで文字数カウンタ(`text-caption` / `color-text-muted`): 「12/30」

### 2. FieldDateRange(日程)

- ラベル: 「日程 ※必須」
- 横並び2項目(375px幅では縦積みでも可、frontend-dev裁量):
  - 開始日: 日付入力(`<input type="date">`相当)、ラベル「開始日」
  - 終了日: 日付入力、ラベル「終了日」
- 開始日のみ入力された状態で終了日が未入力の場合、送信時に終了日必須のバリデーションが働く(下記参照)

### 3. FieldTripType(遠征タイプ)

2列グリッドの単一選択チップ4種(ライブ/イベント参戦・聖地巡礼・舞台/観劇・その他)。

- 高さ48px以上、`radius-md`(12px)。**ピル型(`radius-full`)ではなく角丸にして、入力欄と同じ矩形の系統に揃える**
- 選択中: `sakura`の枠線 + `sakura-soft`背景 + `sakura-ink`の太字
- 非選択: `paper-dashed`の枠線 + 白背景 + `ink`の中太


### 4. FieldPurpose(目的・任意)

- ラベル(必須マーク無し): 「目的(任意)」
- テキスト入力(1行)
- プレースホルダー: 「例: ○○ライブツアー 東京公演」
- 文字数上限: **50文字**(仮置き。仕様に数値指定が無いため)
- 入力欄下に右寄せで文字数カウンタ: 「0/50」

### 5. FieldCover(カバー・任意)

色8種 / 絵文字8種のプリセットから1つ選ぶ(`docs/design/tokens.md`「6.」)。

- 上部に「色 / 絵文字」の切替(`radius-full`のセグメント。選択中は`sakura-soft`背景+`sakura-ink`の太字)
- 下に4列グリッドのプリセット(44×44px、`radius-md`)
  - 色: ベタ塗り / 絵文字: `paper-dashed`枠 + 白背景
  - 選択中は`sakura`のリング(`ring-2` + `ring-offset-2`)で示す。**リングは面の色に埋もれないよう外側に余白を取る**
- 色/絵文字を切り替えると選択状態はリセットする(仮置き)


### 6. SubmitButton(送信ボタン)

`sticky bottom-0`の帯に置く全幅ボタン。`sakura`背景 / `radius-btn`(14px) / 高さ52px / 15px・700。

送信中は`paper-track`背景 + `ink-faint`文字の無効表示にし、文言を「作成中…」に変える
(半透明にすると押せそうに見えるため、無効は色で示す)。


## 状態

| 状態 | 表示 |
|------|------|
| 初期(空フォーム) | 全項目未入力。遠征タイプ・カバーも未選択。文字数カウンタは「0/30」「0/50」 |
| 入力中 | 各項目に値が入るにつれ文字数カウンタ更新、チップ・スウォッチの選択状態が即時反映される。バリデーションエラーは基本的に**送信ボタン押下時**にまとめて表示する(入力の都度は表示しない) |
| エラー(バリデーション) | 該当項目の入力欄枠線が`color-error-border`に変化し、入力欄直下にエラー文言(`text-caption` / `color-error`)を表示する。複数項目がエラーの場合は全項目分表示し、画面は最初のエラー項目までスクロールする |
| 送信中 | SubmitButtonが「作成中…」+スピナー+無効化。フォーム項目はすべて編集不可(`disabled`)にする |
| 完了 | 成功時は画面遷移するため完了状態の据え置き表示は無し。作成された`shiori.id`で`/shiori/[id]/packing`(S3a・持ち物タブ)へ遷移する |
| オフライン | ゲスト保存はIndexedDBへのローカル書き込みのみのため、オフラインでも通信不要で作成・遷移が成立する。オフライン専用の表示分岐は無し |

## バリデーション文言

| 項目 | 条件 | 文言 |
|------|------|------|
| タイトル | 未入力で送信 | タイトルを入れてください |
| タイトル | 30文字を超える | タイトルは30文字以内で入力してください |
| 開始日 | 未入力で送信 | 開始日を選択してください |
| 終了日 | 未入力で送信 | 終了日を選択してください |
| 終了日 | 開始日より前の日付 | 終了日は開始日以降の日付にしてください |
| 遠征タイプ | 未選択で送信 | 遠征タイプを選んでください |
| 目的 | 50文字を超える | 目的は50文字以内で入力してください |

カバーはバリデーション対象外(未選択時は既定値`cover-color-1`を自動採用するため)。

## タップ時の挙動

| 要素 | 挙動 |
|------|------|
| 戻るボタン | 直前の画面(通常はS1)へ戻る。入力途中でも確認ダイアログは出さない(下書き保存機能はF1仕様に無いため実装しない) |
| 遠征タイプのチップ | タップしたチップを選択状態にする(単一選択、他のチップの選択は自動解除) |
| カバーのトグル(色/絵文字) | 表示するプリセットグリッドを切り替える。切り替えても選択済みの値は保持しない(色→絵文字→色と切り替えた場合は再度未選択状態に戻る、仮置き) |
| カバーのスウォッチ/絵文字 | タップしたものを選択状態にする(単一選択) |
| SubmitButton | バリデーション実行 → エラー無ければ`shiori`レコードをIndexedDBへ作成 → `/shiori/[id]/packing`へ遷移。エラーがあれば該当項目にエラー表示 |

## 遠征当日の利用シーン確認

- S2は事前準備画面のため遠征当日の利用は想定外だが、片手操作前提でチップ・スウォッチのタップ領域は44px以上を確保
- 通信不要(IndexedDBのみ)のため電波が弱い環境でも作成できる

## 不明点・仮置き(完了報告にも記載)

- 文字数上限(タイトル30文字/目的50文字)は仕様に数値記載が無いため仮置き
- カバーの選択UIをプリセットスウォッチ8色+絵文字8種からの選択方式にした(自由な色ピッカーやカスタム絵文字入力は仕様に指定が無く、W1では実装ライブラリを増やさない方針に合わせ仮置き)
- カバー未選択時のデフォルト値(`cover-color-1`)は仕様に記載が無いため仮置き
- 色/絵文字トグル切替時に選択状態をリセットする挙動は仕様に記載が無いため仮置き
