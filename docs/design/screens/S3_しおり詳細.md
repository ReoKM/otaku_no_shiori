## ノート演出(2026-07 UI刷新)

「しおり=旅のノートを開いている」感覚を操作感に宿らせる演出。実装は`src/app/shiori/[id]/layout.tsx`+`globals.css`の`.s3-*`クラス。色・影は既存トークン(`neutral-*`/`shadow-*`)のみ使用し、新色トークンは追加していない。

### 1. 綴じリング(`.s3-note-binding`)

- コンテンツ左端(幅24px)に、スパイラルノートの綴じ具を思わせる縦一列のリング(穴+リングのドット)を表示する
- `position: fixed`でスクロールに追従させない。ヘッダー(z-10)・タブバー(z-20)の下に潜る
- 描画はCSSの`radial-gradient`の`repeat-y`のみ(画像アセット無し)。装飾のみ(`aria-hidden`)
- コンテンツ(紙)は左24pxを空けて配置する

### 2. 紙(ページ)の質感(`.s3-paper`)

- タブコンテンツ全体を「紙」として背景`color-bg-app`(`neutral-50`)で描き、シェル背景は`bg-neutral-100`に落として紙を浮かせる
- 左端(綴じ側)に内側シャドウ、全体に`shadow-md`で立体感を出す
- ごく薄い紙ノイズ(インラインSVGの`feTurbulence`、透過3%)と、右端に「ページの厚み」を思わせる1pxストライプを`::after`で重ねる(画像アセット無し・操作を妨げない`pointer-events: none`)

### 3. タブ間のスワイプ移動

- タブコンテンツ領域の左右スワイプで隣のタブへ移動する(左スワイプ=次のタブ、右スワイプ=前のタブ。タブ順は持ち物→TODO→旅程→ログ)
- 端では何もしない(持ち物より前・ログより後ろは無し)
- 誤爆防止: 水平48px以上の移動、かつ縦移動が水平の50%以下(水平から約27度以内)の場合のみ発火。最初のまとまった移動(10px)で縦/横の軸をロックし、縦スクロール開始後は発火しない。2本指(ピンチ)や並べ替えドラッグ(`touch-none`要素)上のタッチも対象外
- 判定ロジックは`src/lib/tab-swipe.ts`(単体テスト付き)

### 4. ページめくりトランジション v2・リーフフリップ(`.s3-page-turn-next` / `.s3-page-turn-prev`)

2026-07-19刷新(第2弾フィードバック「捲れ感が弱い」への対応。企画: `docs/design/notes/2026-07-19_S3ノートUI-v2企画.md`)。出ていく側の紙も同時にアニメーションさせ、「1枚の紙がめくれた」物語を作る。

- 進む(後ろのタブへ): 新ページは下敷きとしてごく小さく滑り込むだけ。その上を「めくられた前ページの裏面」(疑似要素、紙色+綴じ側陰影のグラデーション)が綴じ軸の`rotateY 0→-100deg`で払われる。`backface-visibility: hidden`により90度を超えた瞬間に自然に消える。easingはease-in系(実物の紙が倒れるほど加速する動き)
- 戻る(前のタブへ): 新ページ自体が「左に倒してあった紙が起き上がって開く」動き(`rotateY -75deg→0`、ease-out系=開き切る直前に減速)。回転中は綴じ側の陰影+右への飛び影を疑似要素で重ね、開き切ると消える
- 時間は0.45秒(v1の0.3秒では紙の回転を目が追えないため延長)
- 本格的なページカール(Apple Books/WebGL相当)は作らない(オーナー指示)。ライブラリ追加無し(CSSのtransform/box-shadow/gradientのみ)
- `prefers-reduced-motion: reduce`環境ではアニメーション無し

## コンポーネント構造

```
<Header>
  <BackButton />
  <ShioriTitleBlock title date />
</Header>
<TabBar activeTab>
  <Tab id="packing" label="持ち物" />
  <Tab id="todo" label="TODO" />
  <Tab id="itinerary" label="旅程" />
  <Tab id="log" label="ログ" />
</TabBar>
<TabContent>
  {activeTab === "packing" && <PackingTab />}   // S3a_持ち物.md
  {activeTab === "todo" && <TodoTab />}         // S3b_TODO.md
  {activeTab === "itinerary" && <ComingSoon feature="旅程" />}
  {activeTab === "log" && <ComingSoon feature="ログ" />}
</TabContent>
```

### ComingSoon(準備中ブロック、旅程/ログ共通)

- 画面中央に配置(上下`space-10`の余白)
- アイコン代わりの絵文字(`text-heading-lg`サイズ、装飾のみ): 「🚧」
- 見出し(`text-heading-md`): 「{機能名}は準備中です」
- 説明文(`text-body-sm` / `color-text-secondary`): 「近日公開予定です。もうしばらくお待ちください。」
- ボタン等の操作要素は置かない

## 状態

| 状態 | 表示 |
|------|------|
| ローディング(IndexedDBから該当`shiori`読込中) | ヘッダーのタイトル部分をスケルトン(`color-bg-disabled`のブロック)にする。タブバーは表示するが押下不可とし、操作不能であることが視覚的に伝わるようタブバー全体を`opacity-50`でグレーアウトする(押しても反応しない状態を通常時と同じ見た目で放置しない) |
| 通常表示 | ヘッダーに実際のタイトル・日程、選択中タブの内容を表示 |
| 該当しおりが存在しない(不正なid・削除済み) | タブコンテンツエリアに「このしおりは見つかりませんでした」(`color-error`)+「一覧に戻る」ボタン(`/`へ遷移)。ヘッダーのタイトルは「しおりが見つかりません」と表示 |
| 準備中タブ表示中 | ComingSoonブロックを表示(上記) |
| オフライン | データはIndexedDBのローカル参照のみのため通信不要。オフライン専用の表示分岐は無し |

| 要素 | 挙動 |
|------|------|
| 戻るボタン | `/`(S1)へ遷移 |
| 持ち物タブ | `/shiori/[id]/packing`へ遷移(タブ切替) |
| TODOタブ | `/shiori/[id]/todo`へ遷移(タブ切替) |
| 旅程/ログタブ | 同一シェル内でComingSoonブロックを表示する(専用ルートを割り当てるかはfrontend-dev裁量。W1ではルーティング未確定のため、タブ状態のみで切り替える実装でよい) |
| 「一覧に戻る」ボタン(しおりが見つからない場合) | `/`(S1)へ遷移 |
