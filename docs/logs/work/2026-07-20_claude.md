## 23:15 共有画像に写真が載らない問題の修正(S5)

- Goal: 「共有画像の作成で画像が読み込まれない」問題の原因を特定し、写真入りの共有画像が生成できる状態にする
- 結果: 達成
- やったこと:
  - 調査: satori→resvgの写真描画(PNG/JPEG data URL)・サムネイル表示・選択→送信のクライアント経路をvitest+Playwrightで検証し、いずれも正常であることを確認
  - 原因特定: ログ保存写真は長辺1600px・品質0.85のJPEGで実写真だと1枚1〜2MB。data URL化(約1.33倍)して写真2〜3枚をJSONに載せるとNetlify Functionの検証上限MAX_PAYLOAD_BYTES=5MB(およびLambdaボディ上限6MB)を超えて400になり、生成失敗→写真なしで再生成する流れになっていた(実写真相当のノイズJPEG3枚で8.07MBを実測)
  - 修正: ShareTab.handleGenerateで送信前に写真をresizeImageFile(長辺1080px・品質0.8)で再縮小してからdata URL化(縮小失敗時は元Blobへフォールバック)。共有画像テンプレの写真枠は最大幅952pxのため画質影響なし
  - 検証: Playwrightで実写真相当3枚を選択→ペイロード8.07MB→1.08MBに減少し写真3枚とも送信されること、プレビュー表示まで成功することを確認
  - lint / tsc --noEmit / test(317件)成功を確認
- できていないこと: 本番/プレビュー環境での実機確認(push後のNetlifyプレビューで確認する。この環境からは*.netlify.appへの外部接続が許可されておらず直接検証不可)
- 不明点・仮置き: 再縮小パラメータ(長辺1080px・品質0.8)は仕様に指定が無いため仮置き(テンプレ写真枠の最大幅952pxに余裕を持たせた値)
- 成果物: PR #74、src/components/share/ShareTab.tsx
- 作業ログ: docs/logs/work/2026-07-20_claude.md
