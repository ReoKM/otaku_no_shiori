# 作業ログ

全エージェントは、タスクごとに作業ログをこのディレクトリに残す(CLAUDE.md「タスク実行プロトコル」参照)。

## ルール

1. ファイル名: `YYYY-MM-DD_<エージェント名>.md`(例: `2026-07-14_frontend-dev.md`)
2. 1日1ファイル。同じ日の2タスク目からは同じファイルに追記する
3. タスク1件につき下のテンプレートを1ブロック書く
4. ログを残していないタスクは未完了とみなす

## テンプレート

```markdown
## HH:MM <タスク名>
- Goal: (開始時に立てたGoal)
- 結果: 達成 / 部分達成 / 未達
- やったこと:
  - (箇条書き)
- できていないこと: なし(無い場合も「なし」と明記)
- 不明点・仮置き: なし(同上)
- 成果物: (PR番号・ファイルパス)
```

## 記入例

```markdown
## 14:30 F2持ち物リストの実装
- Goal: F2がゲスト保存で動きPRがマージ可能になる
- 結果: 部分達成
- やったこと:
  - チェックリストUI実装、テンプレ定数追加、テスト3件
- できていないこと:
  - 並べ替えのドラッグ操作が未実装(タップ移動のみ)。Issue #18 に切り出し
- 不明点・仮置き:
  - テンプレの並び順が仕様に無いため五十音順で仮置き
- 成果物: PR #17
```
