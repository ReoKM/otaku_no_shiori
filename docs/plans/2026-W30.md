## F8のブロック要因(オーナー作業待ち)

F8着手前に以下が必要(supabase/README.md・PR #32参照):

1. SQL Editorで `supabase/migrations/0001_initial_schema.sql` を実行
2. Project URLとanon public keyを取得し、Netlify環境変数 `NEXT_PUBLIC_SUPABASE_URL` および `NEXT_PUBLIC_SUPABASE_ANON_KEY` に登録
3. Supabase AuthでX/Google OAuthプロバイダを設定(各プラットフォームのアプリ登録が必要)

完了連絡をもらってから着手する。利用枠の残量次第では翌週(枠リセット後)に回す。
